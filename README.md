## Языки

- **Узбекская версия — главная**: `https://aibuyurtma.com/` (`index.html`, `privacy.html`). Реклама идёт на Узбекистан.
- **Русская**: `https://aibuyurtma.com/ru/` (`ru/index.html`, `ru/privacy.html`). Переключатель UZ/RU — в правом верхнем углу первого экрана, метки рекламы переносит с собой.
- Узбекский текст — `src/i18n/uz.json`: по ключам `data-i18n` из `src/index.src.html`, плюс точные замены в атрибутах и мета (`replace`) и картинки бонуса (`img` → `assets/img/uz/`). Сборка падает, если у ключа нет перевода или в узбекской версии осталась кириллица.
- Перевод: ИИ + слепой обратный перевод 17.10.2026. **Живой носитель ещё не читал.** Файл для него — `python3 scripts/docx_native.py` → `research/13-lending-intensiva/для-носителя/Лендинг мини-курса RU-UZ — на вычитку.docx` (Русский | Узбекский | Правки), копия на Рабочем столе. Правки носителя вносить в `src/i18n/uz.json` (и `privacy.html`), потом сборка.
- Логотип в узбекской версии — «AI BUYURTMA»; латиница граффити-шрифтов — `assets/fonts/Rubik*-latin.woff2` (Google Fonts, OFL), подключена в `css/mini.css`.
- В `dataLayer` у всех событий есть `lang` (`uz` / `ru`).

## Как устроено

- Статичная страница без фреймворков: `index.html`, `css/`, `js/`, `assets/`.
- `index.html` (UZ) и `ru/index.html` (RU) собираются из `src/index.src.html` командой `python3 scripts/build.py`. Сами страницы руками не править.
  Скрипт подставляет детали образца из `src/parts.json`, заголовки под хуки из `js/hooks.js`, типографику и метки версий файлов.
- `css/style.css` и `css/fonts.css` — копии страницы курса байт в байт. Всё своё — в `css/mini.css`.

## Настройки — `js/main.js`

- `BOT_USERNAME` — имя бота мини-курса без @: `uz_ai_school_bot` (Вася, 17.10.2026). Если стереть, кнопки ведут на `https://t.me/`.
- Метка для бота уходит в параметр `start`: `vm-<utm_source>-<utm_campaign>-<utm_content>` или `vm-direct`, не длиннее 64 знаков. Источник — последний: метки из адреса запоминаются в браузере.
- События уходят в `window.dataLayer`: `page_view`, `cta_click`, `block_view`, `faq_open`. Метрики нет.
- Пиксель Meta — датасет `UZ_course_pix` (`3217856658404769`) в БМ кабинета «Uzbekustan RK». Базовый код с `PageView` — в `<head>` (`src/index.src.html`), на обеих версиях.
  `Lead` уходит из `js/main.js` при нажатии любой кнопки в бота, один раз за загрузку страницы: на это событие оптимизируются группы объявлений.
  Под автотестами (`navigator.webdriver`) пиксель не грузится, чтобы `qa.py` не слал события в Meta.
- Абзац о пикселе в политике — `privacy.html` (UZ) и `ru/privacy.html` (RU), 17.10.2026. Узбекский абзац носитель ещё не читал.

## Заголовки под хуки

Заголовок первого экрана меняется по слову в `utm_content`. Ищется целое слово, например `hook_compare_v1` или `reels-now-2`:

| Слово в метке | Заголовок |
|---|---|
| `compare` | Такси, смены, Uzum или онлайн-профессия… |
| `math` или `math_b` | $1000 в месяц — это 3–4 заказа от бизнеса по $300… |
| `math_a` | $1000 в месяц — это не пассивный доход… |
| `now` | Раньше сайт учились делать годами… |
| `zero` | Можно ли освоить онлайн-профессию с нуля… |
| `clients` | Умеешь делать с ИИ, но нет клиентов?… |
| `home` | Научим делать сайты и ботов для бизнеса твоего города… |

Без метки стоит основной заголовок. Все 8 заголовков лежат в разметке. Нужный показывает скрипт в `<head>` до отрисовки, поэтому заголовок не мигает.

## Варианты первого экрана

Для выбора — по ссылке, без метки стоит вариант A:

| Ссылка | Что |
|---|---|
| `/` | A — фото Никиты: говорит с клиентом по телефону, ноутбук в руке; на телефоне текст, кнопка, потом картинка |
| `/?hero=b` | B — Никита показывает сайт владельцу пекарни; на телефоне картинка первой |

Метку ставит тот же скрипт в `<head>` (`data-hero` на `<html>`), картинки переключает `css/mini.css`.

## Проверки перед публикацией

```bash
python3 scripts/build.py
node --test tests/*.test.mjs
node scripts/check-texts.mjs
python3 scripts/qa.py
```

- `check-texts` — каждая строка согласованного текста стоит на странице, и лишнего текста нет. Читает `research/13-lending-intensiva/ЛЕНДИНГ-ФИНАЛ-RU.md` рядом с репозиторием.
- `qa.py` — Chromium на 6 размерах экрана × 8 заголовков и картинки первого экрана B и C. Проверяет:
  - кнопка видна в первом экране;
  - нет прокрутки вбок;
  - нет ошибок в консоли;
  - нижняя панель работает;
  - в вопросах открыт один пункт;
  - мельче 14 px текста нет.
- По живому адресу: `python3 scripts/qa.py https://vasiliy0444.github.io/ii-na-zakaz-mini/`.
